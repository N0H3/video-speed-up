# Changelog

## 1.0 — 13 ноября 2026

Первый публичный релиз.

### Возможности
- Управление скоростью видео перетаскиванием мыши: **1.0× – 4.0×** с шагом 0.2×.
- Зажатие ЛКМ на видео на 200 мс включает режим управления.
- Тяга **вправо/влево** — изменение скорости, **вверх** — фиксация (скорость остаётся
  после отпускания), **вниз** — сброс на 1.0×.
- Минимальный HUD: огонёк и белая цифра с чёрной обводкой в правом верхнем углу видео,
  без фона, рамок и ползунков. При фиксации огонёк подсвечивается.
- Работает в обычном DOM, в open shadow DOM и в iframe (`all_frames`).
- Рекламные видео (VAST/VPAID/преролл) отсеиваются по контейнерам-предкам.
- Кнопки плеера (пауза, звук, перемотка, качество, полный экран) не перехватываются.
- Выделение и копирование текста на странице не ломается: `user-select` отключается
  только на время самого перетаскивания.
- Включение/выключение из popup со синхронизацией состояния между вкладками.

### Устойчивость
- Защита от «залипания»: сброс по `pointerup`, потере фокуса окном, скрытию вкладки,
  уходу курсора за пределы документа, `e.buttons === 0` и watchdog-таймеру.
- `document.body` может быть `null` (`about:blank`-фреймы, документы без `<body>`) —
  все обращения идут через безопасный хелпер с fallback на `document.documentElement`.
- Все обработчики событий и фоновые таймеры обёрнуты в `try/catch` — ошибка расширения
  не попадает в консоль страницы.
- SVG-огонёк строится через `createElementNS`, без `innerHTML`, поэтому HUD работает и на
  сайтах с Trusted Types (YouTube, Google, GitHub и др.).
- `blur` слушается без `capture` — сброс происходит только при потере фокуса окном,
  а не при фокусировке любого элемента страницы.
